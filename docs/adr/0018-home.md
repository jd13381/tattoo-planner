# ADR 0018: Home, the start tab, and the active variant per region

- Status: accepted (2026-11-06, Jan's test notes; design by Claude, see docs/claude-decisions.md)
- Context: Jan: "Es braucht eine Art Home-Button, in dem ich den ganzen Körper sehe, den ich zusammengestellt hab. View only, mit der Möglichkeit, zu den Detail-Layout-Seiten zu kommen. Der Home-Bereich sollte fancy aussehen, weil es das Erste ist, das User sehen." And: "Ich sehe nicht, wie ich in den Sample Mode komme." Jan decided: Home becomes the start tab, and for each person and region one layout variant is marked active; Home shows the active variants.

## Decision

### Active variant

- Stored per person in `project.yaml` (`active: { <region>: <layout name> }`, ADR 0017), so it travels with the project and stays human-editable. A region without an entry, or whose entry names a file that is gone or belongs to another region, shows its **first variant by name** (`activeVariant` in `src/project/persons.ts`).
- The Layout tab has a star button right of the variant picker: filled for the active variant, "Set as active" otherwise (disabled for an unsaved new variant and in the read-only sample). Opening a region without a variant opened before goes to its active variant; the Layout tab starts on the left arm's active variant.

### Home

- First tab and the default route (`#home`, an empty or unknown hash). Full-bleed: a 3D stage on the left, a side column on the right.
- **Stage:** the current person's whole body (the full-body meshes of `BodyViewer`, ADR 0011) with every region textured by its active layout in reference mode (`RegionTextureSource`), studio lighting (warm key, soft fill, two cool rim lights), a contact shadow, a token-based radial backdrop with a soft spotlight and floor glow. A slow turntable (OrbitControls `autoRotate`, one turn in about 75 s) stops as soon as the user drags or zooms, and the play/pause button and the Front/Back/Left/Right presets control it; with `prefers-reduced-motion` it starts paused. Hovering a region highlights it and names region, variant and coverage under the figure; a click opens it in the Layout tab. The hero top left shows the person's avatar, name, body and "n of 5 regions planned".
- **Side column:** the people of the project as cards (switch, **Add person** inline, **Manage** → Settings → Project), then one card per region with a thumbnail of its unwrap, the active variant (star when marked), coverage %, motif count, variant count and a coverage bar; hovering a card highlights the region in 3D and the other way round. A click opens the region's active variant in the Layout tab, or a new layout on an empty region.
- **Empty state:** a person without layouts sees the plain body and a card "Nothing planned yet" with **Start on the left arm**.
- **Sample:** in a project, an "Explore the sample" card at the bottom of the column; inside the sample, a banner with **Save as my project…** and **Leave the sample** (back to the project open before, or the start screen). The start screen puts **Explore the sample** first. The sample can now also be opened when `TATTOO_DATA_DIR` fixes the project (it is never remembered; leaving it returns to that folder); saving it as a project stays refused there.
- **Header:** a person chip (avatar and name, collapsing to the avatar when a tab fills the top bar) opens a list to switch person, **Add person** and **Manage people**.
- **The way back (2026-11-06):** the Home tab carries a house icon. A region opened from Home is a new history entry (`FROM_HOME_STATE`, `src/settings/routes.ts`), and the Layout tab then starts its picker with **‹ Home › person ›**. That button, the browser's Back, the Home tab and Esc (once nothing is selected) return to Home with the same turntable state and camera angle.
- **Theming:** only CSS custom properties from `src/styles.css`; the backdrop and glow are `color-mix` of tokens, and avatar colours are a per-person hue (`personHue`) with saturation and lightness from `--avatar-s` / `--avatar-l`, so a light theme only redefines tokens.
- Region stats come from `src/home/model.ts` (`homeRegions`, `regionStats`: the coverage classifier at 2 px/cm), unit-tested.

## Alternatives

- **Home as a mode of the Layout tab's full-body view.** Mixes viewing with editing and cannot be the start screen. Rejected.
- **Active variant in the user config.** Would differ between computers and not travel with the project. Rejected.
- **An environment map (HDRI) for the studio look.** Needs an image file (no binaries in the repo, offline-first). Lights and CSS give enough.

## Consequences

- Home unmounts when another tab is open (a second WebGL context only while it is shown).
- The person switch reloads the page (ADR 0017); Home is where the app returns to.
